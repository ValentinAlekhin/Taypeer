## Проверяемое утверждение

Один выбранный набор ревизий GPUI и GPUI Kit позволяет реализовать обязательный
интерфейс на macOS 15+ Apple Silicon и Android 12+ ARM64. Мобильный форк из Zedra —
кандидат для исследования, а не доказательство совместимости.

## Порядок работы

1. Проверить актуальные первичные документы и исходники GPUI, Kit и мобильного форка.
   Зафиксировать полные git SHA, лицензии, Rust, JDK, SDK/NDK и команды сборки.
2. Создать в этой папке изолированный Rust workspace с собственным lockfile.
   Собрать минимальное приложение с настоящими компонентами Kit на обеих ОС.
3. Включить дерево/список с прокруткой, форму с защищённым вводом, диалог,
   переключение en/ru, изменения размеров и мобильную навигацию. Проверить общий
   слой двух встроенных палитр из TOML, три режима выбора темы и события смены
   режима ОС, включая повторное чтение после возвращения из фона.
4. Добавить минимальные платформенные вызовы для буфера, файлового диалога,
   биометрии и событий жизненного цикла. Использовать только искусственные данные.
5. Пройти матрицу на целевом Android и macOS, сохранить воспроизводимые результаты.

Для каждого результата записать устройство, ОС, GPU/рендерер, SHA, команды,
шаги, ожидаемый/фактический результат и ссылки на доказательства без секретов.
Эмулятор полезен дополнительно, но не закрывает требование реального устройства.

Недоступный режим ОС проверить подменой платформенного источника: последний
известный системный режим, иначе светлый. При ручной фиксации смена ОС не влияет
на активную палитру. Проверка касается встроенных тем первой версии;
пользовательский TOML и редактор цветов относятся к будущей персонализации.

## Условие завершения

Воспроизводимые сборки обеих платформ и пройденная матрица с Kit. После этого
перенести проверенные зависимости и сборочную конфигурацию в основной workspace.
Если обязательный сценарий не работает, записать проблему и границы исправления.
Замена UI нативным Android или исключение Kit не закрывают эту проверку.
