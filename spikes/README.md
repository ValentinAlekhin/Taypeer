## Решение по фронтендам — 2026-09-08

macOS сохраняет Rust + GPUI + GPUI Kit. Android использует отдельный Kotlin +
Jetpack Compose / AndroidX фронтенд с UniFFI к общим Rust-сервисам.
Портирование GPUI/Kit на Android больше не является условием основной реализации:
совместимость исходной гипотезы не подтверждена.

Бизнес-правила не дублируются во фронтендах. Текущие границы и обращение с секретами
описаны в [архитектурных принципах](../docs/architecture.md).
2026-09-09 решение перенесено в спецификацию, документацию и правила темы макетов.
Исторические отчёты сохраняют результаты исходной гипотезы.

## Завершение UI-исследования — 2026-09-09

Стек принят с известными ограничениями. Проверенной части достаточно, чтобы
перейти к экранам приложения: список БД → разблокировка → список записей,
пока на искусственных данных с общим Rust API.

Завершение исследования не означает полной UI-приёмки. Оставшиеся проверки ввода,
кадров, реальных устройств, платформенных интеграций и очистки UI перенесены в
[этап 2](../docs/roadmap.md#2-локальная-бд-и-первая-вертикаль-интерфейса).

## Завершение этапа spike — 2026-09-09

По решению владельца результаты encrypted-sync приняты вместе с UI-исследованием:
прототипы, воспроизводимые сценарии, логи и ограничения зафиксированы.
Повторный исследовательский этап для начала первой искусственной вертикали
не требуется. Её реализация на момент решения ещё не начата.

Отрицательная проба памяти Automerge и непроверенные сценарии не считаются
успешной приёмкой. До работы с настоящими паролями необходимо закрыть проверки
безопасности, полного криптографического формата и обращения с секретами на обеих ОС.

## Проверки в ходе разработки

Открытые задачи ведутся только в [roadmap](../docs/roadmap.md), методы и матрица —
в [testing](../docs/testing.md). Подробные результаты хранятся в отчётах выше.
Успешный локальный эксперимент не заменяет проверку безопасности и целевых ОС.
