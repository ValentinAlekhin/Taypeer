# Точка продолжения — 2026-09-22

Первый этап «Android-runtime» не завершён. Оценка объёма: около 55% этапа
и 15% полного Android-плана; проценты не являются приёмкой функций.
Цель паритета остаётся macOS на `0104543`; текущая реализация также учитывает
последующие command receipts. Матрица реализации и доказательства — в [README](README.md).

## Что уже работает

- Продуктовый Gradle-проект, ARM64 debug APK, отдельный workspace-crate UniFFI
  в `native/`, генерация bindings и проверка 16-КиБ ELF/ZIP, Android CI-задача.
- Compose → общий Rust-генератор, TOML-палитры, en/ru, форма в памяти,
  очистка результата в фоне, Keystore credentials и защищённый буфер.
- Независимые isolated Service, native loading и завершение после смерти host.
  Это процессы проверки границы, ещё не открытые документы.
- Runtime-порты credentials и process control; desktop сохраняет прежний запуск.
- Android flock; явный allocator временного ciphertext в storage/services.
  Изолированный Rust проверяет реальный архив через переданные Binder-дескрипторы,
  без повторного открытия путей и без доступа к каталогам host.
- Адаптер импорта создаёт новую внутреннюю копию, сохраняет источник и отличает
  ошибку от успеха. Пользовательский поток SAF ещё не подключён.

## Следующий срез: настоящий document worker

1. Перед изменением протокола дополнить LikeC4 и проверить всю модель.
   Заменить путь spool в `cipher_ipc`/host callbacks на платформенный обмен
   ciphertext с непрозрачными идентификаторами и временем жизни передачи.
   Desktop получает адаптер каталогов, Android — Binder-дескрипторов.
2. Отделить запуск worker от `NativeProfile` и desktop-путей. Передавать нужные
   авторские полномочия после аутентификации; isolated worker не получает
   Keystore, сеть или доступ к каталогам приложения.
3. Подключить `DocumentService` к общему supervisor через `ProcessLauncher`,
   `ProcessConnection` и `ProcessHandle`. Удалённая остановка не должна ждать
   занятую команду. Сохранить независимый watchdog и двухсекундный срок.
4. Подключить типизированные UniFFI-команды и ответы с идентификаторами БД,
   поколения сессии и запроса; UI отбрасывает поздние ответы.
   Не экспортировать дерево Automerge, ключи чтения и универсальный JSON API.
5. Проверить две искусственные файловые БД, независимую блокировку,
   KDF/запись/зависший вызов, смерть host/worker, неподтверждённый выход,
   сохранённый и несохранённый черновик, read-only и неподдерживаемые файлы.
   После этого собрать debug APK и обновить подтверждённый статус этапа.

`RuntimeHost::open_with_launcher` пока использует desktop spool protocol.
`DocumentService` нельзя объявлять рабочим документным процессом до пунктов выше.
Проверка дескрипторов находится в debug-only service; release его не включает.
Общий storage уже принимает `CiphertextIo` и `TemporaryStorage` — следующий
адаптер должен использовать эти порты без неявного tempdir fallback.

## После runtime

Последовательность исходного плана сохраняется:

1. Каталог, создание/импорт, разблокировка, группы, записи и простой редактор;
   сохранение → завершение приложения → повторное открытие, ошибки записи и SAF.
2. Локальный паритет: поиск/сортировка, несколько БД, пять вкладок,
   общий черновик, история, вложения, иконки и оформление.
3. Lifecycle документа, inactivity, блокировка ОС, SAF-return с разблокировкой,
   очистка секретов и проверка IME/поворота/масштаба 200%.
4. P2P, приглашения, приём ciphertext отдельно от применения, единый network
   host, WorkManager и ограниченная foreground-сессия с остановкой.
5. Полная матрица паритета, release-профиль Rust и внешняя подпись,
   воспроизводимость сборки и актуализация архитектуры/roadmap.

## Проверки на этой точке

Общий check прошёл с `RUST_TEST_THREADS=2`, включая восемь macOS UI-сценариев,
release и smoke. Android build/lint/packaging прошли. На ARM64 AVD API 31,
API 36 и API 36 PS16K прошли по 10 instrumentation-тестов. После этого
негативные варианты descriptor-теста отдельно прошли на API 31 и API 36.
Точные ограничения и первоначальные отказы сохранены в README.

Gradle unit task пока без JVM-тестов; CI ещё не запускался удалённо.
Native Keychain, настоящие устройства, полная проверка памяти и криптографическая
приёмка открыты. P2P Android ↔ macOS/CLI ещё не проверялся. Настоящие пароли
не использовать. SDK, bindings, APK и локальные логи не входят в Git.
