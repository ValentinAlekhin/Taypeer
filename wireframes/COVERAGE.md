# Taypeer: покрытие макетами

Источник требований — [spec.md](../spec.md). Композиция и workflow —
[README](README.md). Матрица описывает **статический дизайн**, не готовность
приложения. Основной набор — ru/dark; перевод строк выполняется при реализации UI.
Android-набор обновлён по текущей v1. Пользовательский редактор темы, планшеты и возможности после v1 не расширяются.

Имена в обратных кавычках — устойчивые имена артбордов в `taypeer.fig`.
Для macOS-экранов используется префикс `macOS /`, для форм — `Dialog /`.
`States / …` и `Menus / …` содержат подписанные фрагменты компонентов.
Карты переходов находятся на странице `08 · Карта сценариев`.

## Контракты переходов macOS

1. **Изменённая форма.** Смена записи, группы, БД, возврат, отмена редактора и
   закрытие БД открывают `unsaved`. «Сохранить» продолжает переход только после
   валидации и надёжной записи; «Не сохранять» отбрасывает черновик;
   «Остаться» отменяет переход. Это же правило действует для формы группы.
2. **Вкладки.** «Обзор», «Дополнительно» и «Вид» принадлежат одному черновику.
   Переключение вкладки не подтверждает его. В просмотре отсутствуют команды
   изменения; свойства всегда доступны только для чтения.
3. **История.** Восстановление и очистка сначала проходят `unsaved`, затем
   собственное подтверждение. Сравнение оставляет черновик. Полный просмотр
   исторической версии использует те же вкладки в режиме чтения с датой версии.
4. **Получение БД.** После разрешения управляющего выбирается место через
   системный Save panel. Успешная загрузка переводит в `unlock`; отмена возвращает
   к получению, а прерванная передача предлагает продолжение той же загрузки.
5. **Импорт.** После чтения источника `import-review` показывает новую БД и
   сводку. «Подробный отчёт» использует `transfer-report` в режиме импорта:
   метаданные KeePass и поддерживаемые поля вместо экспортных потерь CRDT;
   завершающая команда — «Импортировать». Возврат сохраняет параметры формы.
6. **Экспорт.** `export-kdbx` задаёт файл и пароль; `transfer-report` подтверждает
   известные потери. «Создать KDBX» становится доступно только без конфликтов.
7. **Длительные операции.** Общий компонент показывает конкретное действие и
   прогресс. При фиксации результата повторное подтверждение недоступно; ошибка
   возвращает форму и безопасное действие повтора. Таймаут не изображается успехом.
8. **Нативные операции.** Открыть/сохранить файл, выбор каталога, разрешение камеры
   и Touch ID используют интерфейс macOS. Его отмена возвращает фокус к вызвавшей
   команде. Ошибка камеры оставляет ввод кода; ошибка биометрии — мастер-пароль.
9. **Клавиатура.** Cmd+F — поиск, Cmd+S — сохранение редактора; Tab/Shift+Tab,
   стрелки дерева и таблицы, Enter и Escape следуют [контракту README](README.md#клавиатура-и-компоненты).
   Tooltip и доступное имя обязательны для каждой иконки. Ни один переход
   не зависит только от hover, drag или правого клика.

## Искусственные данные и границы проверки

`assets/demo-invitation.json` содержит заведомо недействительный демонстрационный
код. QR сгенерирован для **того же текста**, а не для настоящего сетевого допуска.
Изображение QR состоит из редактируемых векторных модулей; сеть для просмотра
макетов не нужна. Публичные строки генератора и маски полей — примеры для дизайна.

Проверки сериализованного FIG покрывают границы элементов, размещение артбордов,
основную сетку, режимы полей, отсутствие содержимого БД в экране входа,
обязательные поля отзыва, начальное состояние конфликта и наличие ключевых
сценариев. PNG дополнительно проверяются визуально.

Статические макеты не доказывают работу клавиатуры, переключения темы ОС,
биометрии, очистки памяти/буфера, устойчивость файлового формата или сети.
Эта приёмка остаётся в [docs/testing.md](../docs/testing.md) и
[docs/roadmap.md](../docs/roadmap.md).
