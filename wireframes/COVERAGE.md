# macOS: покрытие первого релиза

Источник требований — [spec.md](../spec.md). Композиция и workflow —
[README](README.md). Матрица описывает **статический дизайн**, не готовность
приложения. Основной набор — ru/dark; перевод строк выполняется при реализации UI.
Android, пользовательский редактор темы и возможности после v1 не расширяются.

Имена в обратных кавычках — устойчивые имена артбордов в `taypeer.fig`.
Для macOS-экранов используется префикс `macOS /`, для форм — `Dialog /`.
`States / …` и `Menus / …` содержат подписанные фрагменты компонентов.
Карты переходов находятся на странице `08 · Карта сценариев`.

## Матрица требований

| Требование / точка входа | Экран или форма | Состояния и результат |
|---|---|---|
| Запуск приложения, последние БД | `welcome`, `Menus / navigation` | Всегда приветствие; автоматической разблокировки нет. Недоступный файл → повторный выбор; исходный путь не создаётся заново |
| Создать БД | `create` → `empty` | Название, описание, точный непустой пароль, повтор, качество, KDF 0,5–5 с и путь файла. `States / session`: выполнение без отмены, ошибка с сохранением ввода |
| Открыть .taypeer | Системный выбор → `unlock` | Файл, путь, пароль, возврат, фактическое время подготовки ключа. Ошибки доступа, пароля, повреждения и совместимости показаны в листах состояний |
| Разблокировка и Touch ID | `unlock`, `States / session` | Биометрия включается для конкретной БД на этом Mac после входа паролем. Недоступность → пароль; ротация → новый пароль и повторное включение биометрии |
| Блокировка, локальный черновик | `unlock`, `unsaved`, `States / session` | Контент целиком заменяется входом. Восстановить/удалить сохранённый черновик; ошибка его записи не отменяет блокировку |
| Несколько БД | `Menus / navigation`, `settings-locked` | Селектор открытых и заблокированных БД, создание/открытие/получение/закрытие. Закрытие последней БД → `welcome` |
| Пустое дерево, первая группа | `empty` → `group` → `new-entry` | Ноль начальных групп, создание записи недоступно. Новая группа выбирается. Корзина доступна и при пустом дереве |
| Создание, изменение, клонирование группы | `group`, `Menus / objects` | Единая форма имени, описания и значка. Создание верхнего уровня из пустого места; подгруппа из меню группы. Клон поддерева остаётся у исходного родителя, новые ID и история |
| Перестановка и вложенность групп | `move-group`, `Menus / objects` | Форма выбора родителя и положения, индикаторы вставки между группами и помещения внутрь; недопустимые циклы не принимаются |
| Удаление группы или записи | `delete-objects` → `trash` | Подтверждается точный объект/поддерево. Удаление последней группы возвращает пустое дерево |
| Создать, изменить, клонировать запись | `new-entry`, `edit`, `Menus / objects` | Общий черновик вкладок. Клон открывает форму с текущими данными в исходной группе; новый ID и история появляются после подтверждения |
| Переместить запись | `move-entry` | Выбор существующей группы этой БД; отмена не перемещает запись |
| Поля и срок действия | `main`, `edit`, `States / entry` | Название обязательно; прочие поля необязательны. Пароль скрыт; копирование, генератор, явная favicon-загрузка. Дата включается чекбоксом, доступен ввод даты и предустановки |
| Поиск и колонки | `search`, `no-selection`, `Menus / navigation` | Текущая/все разблокированные БД; общий табличный вид, сортировка, меню колонок. Секреты исключены. Переход к источнику и возврат к запросу; пустые результаты |
| Атрибуты | `Tabs / Дополнительно`, `attribute`, `Menus / objects`, `States / entry` | Добавить, изменить, удалить; непустой уникальный ключ. Защита и значение меняются вместе. В просмотре — раскрыть/копировать, в редакторе — правки |
| Вложения | `Tabs / Дополнительно`, `attachment-rename`, `Menus / objects`, `States / entry` | Добавление, сохранение наружу, переименование, полная замена и удаление. Замена входит в общий черновик; прежнее содержимое остаётся в истории |
| Лимиты и физическое место | `settings-database`, `States / entry`, `States / exchange` | 10 МиБ/100 МиБ по умолчанию; максимум 100 МиБ/1 ГиБ. Превышение после merge сохраняет принятые данные и запрещает добавления. Отдельно — ошибка диска и незавершённое получение |
| Иконка, цвета и изображения | `Tabs / Вид`, `icon-picker`, `color-picker`, `image-url`, `States / entry` | Lucide, файл, явный URL/favicon, сброс оформления. Изображения до 1 МиБ; ошибки не подменяют существующую иконку. Пользовательские цвета сохраняются при смене темы |
| Групповая загрузка favicon | `bulk-icons` | Прямые записи и сохранение существующих значков по умолчанию; рекурсия/замена включаются явно. Частичный отчёт, ошибки отдельных записей не отменяют успех других |
| Свойства записи | `Tabs / Свойства` | Чтение и копирование дат/ID; локальный «Доступ» не синхронизируется и не создаёт версию |
| История, сравнение и восстановление | `Tabs / История`, `Tabs / saved-revision`, `history-compare`, `restore-revision` | Сравнение выбранной версии с текущей; исторические секреты скрыты. Восстановление создаёт новую версию. Сравнение сохраняет черновик |
| Очистка истории | `clear-history`, `Menus / objects` | Точное подтверждение; текущая запись и неразобранные конфликты сохраняются. При черновике сначала Save / Discard / Stay |
| Корзина и её очистка | `trash`, `purge-trash`, `restore-destination` | Просмотр групп/записей, восстановление и окончательная очистка. Без исходной группы обязателен выбор или создание назначения; автоматической служебной группы нет |
| Удержание содержимого после удаления | `States / entry`, `States / conflicts` | История, корзина, конфликты и неприменённые источники удерживают вложения. Очистка не обещает полного сжатия CRDT или стирания старых копий |
| Генерация пароля | `generator`, `generator-exclusions`, `States / entry` | По умолчанию 30 символов, диапазон 1–256, четыре набора, исключения. Изменение параметров обновляет результат. Пустой алфавит блокирует генерацию и использование |
| Парольная фраза | `passphrase` | Английский EFF Long Wordlist, 6 слов по умолчанию, 3–20 слов, дефис. Работает офлайн, язык UI не меняет словарь. «Использовать» меняет черновик, «Закрыть» сохраняет исходный пароль |
| Настройки устройства | `settings`, `settings-locked`, `States / preferences` | Имя, язык, тема, автоблокировка, произвольный положительный таймер буфера/«Не очищать», локальная биометрия, relay. Применение сразу; ошибка оставляет ввод и прежнее действующее значение |
| Тема и размеры | `QA / light-main`, `QA / light-edit`, `QA / light-settings`, `QA / light-unlock`, `QA / light-create`, `QA / minimum-1100-720`, `QA / font-16`, `QA / font-18` | Обе палитры представлены, режим по умолчанию системный. Переключение ОС, фокус, rem и сохранение ввода требуют runtime-проверки |
| Общие настройки БД | `settings-database`, `protection`, `States / preferences` | Имя/описание подтверждаются отдельно; защита и общие лимиты доступны управляющему. Показана выбранная БД и управляющее устройство |
| Пригласить устройство | `devices` → `invite` | Одноразовые код/QR с одними данными, 5 минут, явное подтверждение получателя. `States / exchange`: истечение, отказ, использованный код |
| Получить БД на Mac | `receive` → `scan-qr` → `States / exchange` → `unlock` | Код/камера → ожидание допуска → системный выбор пути → надёжная загрузка → пароль. Отмена и обрыв не выдают частичный файл за готовую БД |
| Получение и применение | `devices`, `unlock`, `States / exchange` | Ожидание пира, соединение, передача, получено, требуется вход, применено, конфликты и ошибка. Direct/relay и отсутствие связи при запрещённых relay различаются |
| Передача управления | `transfer-control` → `accept-control`, `States / exchange` | Оба устройства подключены и разблокированы; подтверждение на обоих. После обрыва продолжается начатая передача; второе управляющее устройство не создаётся |
| Смена пароля и отзыв | `change-password`, `revoke`, `States / session` | Новый пароль и повтор, исходная копия и ротация. Получившие переход устройства требуют нового входа. Отзыв не обещает мгновенного отключения офлайн-пиров или стирания их копий |
| Потеря управляющего | `recover-control` | Новый файл, пароль, ключи и доверенный набор; этот Mac становится управляющим. Старые допуски не переносятся, устройства подключаются заново |
| Конфликт значения | `conflict`, `States / conflicts` | Список, постоянное уведомление, явный выбор без предустановленного победителя, копирование/раскрытие каждого варианта, собственный результат. Общая копия конфликтующего поля недоступна |
| Конфликты удаления, размещения и ключей атрибутов | `States / conflicts` | Восстановить/подтвердить удаление, выбрать размещение без цикла, разрешить совпадающие имена. Защищённые варианты не раскрываются из-за параллельного снятия защиты |
| Отложенные правки | `pending`, `extract-pending`, `delete-pending`, `States / conflicts` | Причина ожидания, изолированный просмотр и маска секретов, назначение для извлечения. Новая запись с происхождением; сетевой допуск не возвращается. Удаление источника требует отдельного подтверждения |
| Поздние правки и отсутствующее содержимое | `States / conflicts`, `States / entry` | Очищенный объект не возвращается автоматически; схема может ждать управляющего; зависимость от отозванного автора требует просмотра; отсутствие blobs ожидает получения |
| Ограниченный доступ и миграция | `States / compatibility`, `migrate`, `States / preferences` | Чтение без записи, неподдерживаемое чтение/обмен, файл без допуска. Явная миграция управляющим после исходной копии, ошибка не повреждает источник |
| Расхождение управления | `States / conflicts` → `recover-control` | Обмен, применение и управление прекращаются; локальное чтение доступно. Продолжение обмена через новый доверенный набор |
| Резервные снимки | `backups`, `restore-backup` | 10 предыдущих исправных автоматических снимков плюс отдельные защитные копии; ручное сохранение наружу и выбор внешнего снимка |
| Восстановление снимка | `restore-backup`, `States / compatibility` | Источник, его пароль при необходимости, состояние и текущая БД. Предварительная копия; новые изменения с сохранением актуальных пароля, схемы и управления |
| Импорт KDBX 3.1/4.0/4.1 | `transfer` → `import-review` → `transfer-report`, `States / compatibility` | Пароль, key file или оба; неподдерживаемые способы доступа объясняются. Отдельная новая Taypeer-БД со своим непустым паролем, отчёт до подтверждения |
| Экспорт KDBX 4.1 | `export-kdbx` → `transfer-report`, `States / compatibility` | Отдельный пароль и файл; конфликты блокируют операцию. Переносимые данные и потери показаны до создания файла |

## Общие контракты переходов

1. **Изменённая форма.** Смена записи, группы, БД, возврат, отмена редактора и
   закрытие БД открывают `unsaved`. «Сохранить» продолжает переход только после
   валидации и надёжной записи; «Не сохранять» отбрасывает черновик;
   «Остаться» отменяет переход. Это же правило действует для формы группы.
2. **Вкладки.** «Обзор», «Дополнительно» и «Вид» принадлежат одному черновику.
   Переключение вкладки не подтверждает его. В просмотре отсутствуют команды
   изменения; свойства всегда доступны только для чтения.
3. **История.** Восстановление и очистка сначала проходят `unsaved`, затем
   собственное подтверждение. Сравнение оставляет черновик. Полный просмотр
   исторической версии использует те же вкладки в режиме чтения с датой версии.
4. **Получение БД.** После разрешения управляющего выбирается место через
   системный Save panel. Успешная загрузка переводит в `unlock`; отмена возвращает
   к получению, а прерванная передача предлагает продолжение той же загрузки.
5. **Импорт.** После чтения источника `import-review` показывает новую БД и
   сводку. «Подробный отчёт» использует `transfer-report` в режиме импорта:
   метаданные KeePass и поддерживаемые поля вместо экспортных потерь CRDT;
   завершающая команда — «Импортировать». Возврат сохраняет параметры формы.
6. **Экспорт.** `export-kdbx` задаёт файл и пароль; `transfer-report` подтверждает
   известные потери. «Создать KDBX» становится доступно только без конфликтов.
7. **Длительные операции.** Общий компонент показывает конкретное действие и
   прогресс. При фиксации результата повторное подтверждение недоступно; ошибка
   возвращает форму и безопасное действие повтора. Таймаут не изображается успехом.
8. **Нативные операции.** Открыть/сохранить файл, выбор каталога, разрешение камеры
   и Touch ID используют интерфейс macOS. Его отмена возвращает фокус к вызвавшей
   команде. Ошибка камеры оставляет ввод кода; ошибка биометрии — мастер-пароль.
9. **Клавиатура.** Cmd+F — поиск, Cmd+S — сохранение редактора; Tab/Shift+Tab,
   стрелки дерева и таблицы, Enter и Escape следуют [контракту README](README.md#клавиатура-и-компоненты).
   Tooltip и доступное имя обязательны для каждой иконки. Ни один переход
   не зависит только от hover, drag или правого клика.

## Искусственные данные и границы проверки

`assets/demo-invitation.json` содержит заведомо недействительный демонстрационный
код. QR сгенерирован для **того же текста**, а не для настоящего сетевого допуска.
Изображение QR состоит из редактируемых векторных модулей; сеть для просмотра
макетов не нужна. Публичные строки генератора и маски полей — примеры для дизайна.

Проверки сериализованного FIG покрывают границы элементов, размещение артбордов,
основную сетку, режимы полей, отсутствие содержимого БД в экране входа,
обязательные поля отзыва, начальное состояние конфликта и наличие ключевых
сценариев. PNG дополнительно проверяются визуально.

Статические макеты не доказывают работу клавиатуры, переключения темы ОС,
биометрии, очистки памяти/буфера, устойчивость файлового формата или сети.
Эта приёмка остаётся в [docs/testing.md](../docs/testing.md) и
[docs/roadmap.md](../docs/roadmap.md).
