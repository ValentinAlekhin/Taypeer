# Покрытие автоматической работы Taypeer

Макеты реализуют композицию из [spec.md](../spec.md) и
[плана автоматизации](../docs/automation-plan.md). Это статические редактируемые
сцены с искусственными данными; они не подтверждают работу runtime, безопасность,
жесты или доступность настоящего приложения.

## Основные сценарии

Имена desktop ниже имеют префикс `macOS /`, Android — `Android /`.
`Dialog /`, `States /` и `Android form /` обозначают формы и образцы компонентов.

| Требование | Desktop | Android | Поведение |
| --- | --- | --- | --- |
| Создать и открыть БД | `welcome`, `Dialog / create`, `unlock` | `welcome`, `Android form / create`, `unlock` | Создание без выбора каталога; внешняя .taypeer становится внутренней рабочей копией, исходник сохраняется |
| Получить БД | `receive`, `Dialog / invite`, `States / exchange` | `receive`, `receiving`, `Android form / invite`, `confirm-device` | Явный допуск, код/QR, надёжная запись внутренней копии; получение ciphertext и применение различаются |
| Записи и группы | `main`, `empty`, `new-entry`, `Dialog / group` | `entries`, `empty`, `new-entry`, `Android form / group` | Поиск, дерево, обычные действия; группа записи необязательна, фильтр «Без группы» |
| Автосохранение | `edit`, `Tabs / Дополнительно`, `Tabs / Вид`, `States / session` | `edit`, `advanced-edit`, `appearance-edit`, `Android states / session` | 500 мс без ввода; переход/закрытие запускает запись сразу. Ввод во время записи сохраняется для следующего снимка, фокус остаётся |
| Несколько черновиков | `drafts`, `States / session` | `drafts`, `Android states / session` | Зашифрованная локальная коллекция; незавершённые новые записи доступны отдельно; открытие объекта продолжает ввод автоматически |
| Ошибка записи | `Dialog / save-error`, `States / session` | `Android states / session` | «Сохранено» только после надёжной записи. Если не сохранены ни БД, ни черновик, редактор остаётся открытым; блокировка выполняется немедленно |
| Объединение и альтернативы | `alternatives`, `States / alternatives` | `alternatives`, `entries-alternatives`, `Android states / compatibility` | Выбор автоматический; исходные значения доступны в истории. Нет обязательного разбора, каждое секретное значение раскрывается и копируется отдельно |
| История всех объектов | `history-compare`, `Tabs / История`, `States / compatibility` | `history`, `history-version`, `history-compare`, `Android states / compatibility` | История записей, групп, названия/описания БД; изменившийся снимок создаёт версию, повтор/no-op/объединение — нет |
| Атрибуты и оформление | `Dialog / attribute`, `icon-picker`, `color-picker`, `States / entry` | `Android form / attribute`, `lucide-picker`, `color`, `Android states / entry` | Одинаковые имена различаются метками ID; защита сохраняет маскирование. Сеть за иконками только по явному действию |
| Вложения | `Tabs / Дополнительно`, `Dialog / attachment-rename`, `States / entry` | `advanced`, `attachment-menu`, `Android form / attachment` | Добавление/замена/переименование автосохраняются, историческое содержимое удерживается; наружный экспорт вложения остаётся явным |
| Удаление и очистка | `trash`, `Dialog / purge-trash`, `clear-history` | `trash`, `purge`, `clear-history` | Удаление сразу в корзину с «Отменить»; удаление выигрывает у конкурентной правки. Окончательная очистка подтверждается |
| Управление и защита | `devices`, `Dialog / revoke`, `change-password`, `protection`, `transfer-control`, `accept-control`, `recover-control` | `devices`, одноимённые `Android form /` | Подключение, передача управления, изменение защиты, отзыв и восстановление доверенного набора остаются подтверждаемыми |
| Отложенные данные | `pending`, `States / alternatives`, `States / compatibility` | `pending`, `pending-source`, `Android states / compatibility` | Недостающие зависимости ожидаются; недостоверные источники изолируются. Независимые допустимые правки продолжают работу |
| Настройки и совместимость | `settings`, `settings-database`, `settings-locked` | `settings`, `settings-database`, `settings-locked` | Локальные настройки применяются сразу, метаданные БД автосохраняются; техническая миграция выполняется управляющим автоматически |
| Платформенные размеры | страница 07 | страница 11 | Тёмная/светлая тема, минимальное окно, 360×640/430×932/844×390, IME, 200% текст и длинные значения |

## Переходы и границы

- Навигация сохраняет снимок сразу, без Save / Discard / Stay. Изменение вкладки
  сохраняет один редактор; ответ записи не заменяет более свежий ввод.
- Блокировка закрывает доступ независимо от ошибки хранения. После входа нет
  предложения восстановления: локальная форма продолжается при открытии объекта.
- Android Back закрывает IME/верхний слой, затем маршрут. Длительный foreground-обмен
  запускается явно и сопровождается тихим обязательным системным уведомлением.
- Альтернативы не требуют выбора и доступны до явной очистки истории.
  «Без группы» доступен при отсутствии групп и после удаления родителя.
- Подтверждения безопасности и окончательной очистки сохраняются. Создание БД
  требует пароля; корректная пустая неизменённая форма записи объект не создаёт.
- KDBX, резервные снимки и их восстановление отсутствуют в выпускаемом наборе.
  История, корзина и восстановление доверенного набора остаются самостоятельными сценариями.

Карты: `Flow / macOS-v1` и `Android flow / v1`. Динамическая проверка остаётся в
[docs/testing.md](../docs/testing.md) и [ANDROID-QA.md](ANDROID-QA.md).
