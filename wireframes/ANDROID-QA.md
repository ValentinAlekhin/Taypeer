# Android: проверка телефонных макетов

## Область

Русский язык, тёмная тема и контрольные светлые экраны в `taypeer.fig`.
Состав и сценарии — [COVERAGE.md](COVERAGE.md), требования — [spec.md](../spec.md).
Проверка FIG относится к статическому дизайну. Android-приложение, переводы,
планшеты и складные устройства здесь не реализуются.

## Воспроизводимая проверка

```sh
rtk proxy python3 wireframes/scripts/design.py build
rtk proxy python3 wireframes/scripts/design.py verify
rtk proxy python3 wireframes/scripts/design.py export
rtk proxy python3 -m unittest discover -s wireframes/scripts -p 'test_*.py'
rtk proxy sh scripts/check.sh
```

`build/qa.json` проверяет сериализованный FIG: границы артбордов/текста,
48 × 48 dp для всех мобильных действий, пересечения видимых областей действий,
системные отступы, взаимное расположение контента, команд формы и IME,
совпадение полей просмотра/редактора, пять вкладок, размеры контрольных телефонов,
пароль/повтор в операциях защиты, независимое копирование вариантов конфликта,
начальное отсутствие победителя и разницу получения/применения.

Исключение из переполнений — только полный контент внутри специально названного
окна прокрутки. Его внутренние узлы проверяются как обычно. Пересечения скрытого
под модальной панелью экрана не считаются одновременными доступными действиями.
Системная клавиатура показана схематично, её клавиши не относятся к контролам
Taypeer. Проверка размеров текстового блока не доказывает отсутствие обрезки
глифов; поэтому требуется просмотр PNG.

При просмотре PNG проверить основной список, оба положения меню, все вкладки,
формы с IME, конфликт, приглашение, сравнение, оба цвета темы, длинные значения,
360 × 640, 430 × 932, горизонтальный 844 × 390 и текст 200%. Для маленького
экрана список заканчивается выше FAB; прокрутка позволяет открыть последнюю
строку целиком. На 200% действия формы располагаются вертикально и остаются
выше клавиатуры. Статус и Home — отдельные системные области.

Для сравнения desktop используется визуальное дерево `source/snapshot.js`
по каждой странице, кроме обзора и Android. Это включает геометрию, текст,
векторы и краски. Старые desktop-сценарии снимков не входят в текущую Android-v1.
Перед заменой FIG обязательна штатная защита `publish` и резервная копия живого
документа; после замены файл повторно открывается в OpenPencil.

## Приёмка на реальном Android — остаётся открытой

| Проверка | Ожидаемый результат |
| --- | --- |
| Меню и краевые жесты | Свайп вправо внутри списка открывает меню. Системный краевой Back сохраняется, Home не перехватывается; в карточке и редакторе свайп меню выключен |
| Группы | Стрелка и название имеют отдельные непересекающиеся области. Название выбирает группу, закрывает меню и показывает только её собственные записи |
| TalkBack | Доступные имена у иконок, объявление выбранной группы/вкладки, логичный порядок фокуса; закрытый или перекрытый слой недоступен. Пароли не читаются до явного раскрытия |
| Шрифт 100–200% | Строки растут без наложений и потери действий; вкладки прокручиваются; полное длинное значение доступно чтением и копированием |
| IME en/ru и поворот | Активное поле и команды видны на всех контрольных размерах, черновик и фокус сохраняются. Секреты не попадают в подсказки клавиатуры |
| Back и черновик | Сначала IME/слой, потом маршрут; изменённая форма требует три варианта. Ошибка записи оставляет ввод и отменяет переход. Смена вкладки не сохраняет черновик |
| Фон и возврат | БД немедленно блокируется, экран/недавние приложения не содержат данных. После входа предлагается сохранённый зашифрованный черновик; ошибка его записи не обещает восстановление |
| SAF / камера / биометрия | Системное подтверждение и отмена возвращают к инициатору. Отказ камеры оставляет ввод кода, отказ биометрии — мастер-пароль. Повторный импорт не заменяет рабочую копию |
| Активный обмен | Уведомление без секретов; в фоне допускается только приём/пересылка шифротекста. После остановки ОС нет обещания точного срока возобновления |
| Получение и запись | Обрыв сети и ошибка диска не показывают успех. Полученные данные применяются только после входа; конфликты требуют отдельного выбора |
| Буфер | 30 секунд, своё значение/чужое копирование, Android без фокуса, чувствительная отметка. Проверка совпадения перед очисткой; безусловное удаление чужого буфера запрещено |
| Роли, восстановление, KDBX | Реальные сервисные проверки допусков, атомарности, формата и потерь выполняются отдельно; статические состояния их не заменяют |

Общая матрица реализации: [docs/testing.md](../docs/testing.md),
платформенные незакрытые проверки: [docs/roadmap.md](../docs/roadmap.md).

## Результат статической проверки · 15 сентября 2026

- 191 артборд всего, 113 Android: 34 экрана, 35 форм, 19 нижних панелей,
  библиотека компонентов, пять листов состояний, 18 контрольных вариантов и карта.
- Проверка кандидата: нет переполнений, узких текстовых блоков и нарушений
  контрактов. Отдельные действия не пересекаются и имеют минимум 48 dp.
- Workflow-тесты: 10 проверок, включая защиту ручных правок, сохранность
  предыдущих экспортов и разделение обзорных листов телефонов/форм/состояний.
- Визуальное дерево всех desktop-страниц, их текста, геометрии и векторов
  совпадает с исходным. В общем обзоре обновлена только строка Android.
- `scripts/check.sh` прошёл полностью: архитектура и ссылки, форматирование,
  проверки/тесты Rust, документация, release-сборка и demo smoke. Native Keychain
  пропущен штатно: он запускается отдельным явным флагом. Rust-код в этой
  работе не менялся.
- Приёмка реального Android из таблицы выше остаётся открытой.
