# План реализации

Первый срез реализован: Rust-ядро, Automerge-документ, общий сервис и macOS demo
работают с искусственными данными в памяти процесса. Состав и ограничения —
в [описании demo](demo.md); долговечное хранение и полная приёмка двух платформ
остаются впереди. [Решения и доказательства исследований](../spikes/README.md)
хранятся в отчётах; здесь — оставшиеся работы и условия перехода.
[Спецификация](../spec.md) определяет приёмку,
[LikeC4](architecture.md) — структуру и взаимодействия.

## Текущая работа: полное Rust-ядро и CLI

[Реализованный командный срез и оставшаяся работа](core-cli.md) фиксируют состояние
нового ядра. CLI и процесс БД уже существуют; это не завершение этапов 3–5.
Экспериментальный контейнер 0 больше не поддерживается; новый контейнер находится
в разработке. Локальные дерево, перемещения, корзина, очистка и разбор поздних источников
реализованы через общие Rust-команды и CLI. Следующий локальный срез также реализован:
вложения, оформление, встроенные/пользовательские иконки, явная URL/favicon-загрузка,
потоковые бинарные секции, черновики и очистка. Текущий контейнер 1 использует
несовместимую dev-схему 4 в новом подписанном пути CLI/macOS; прежние dev-файлы не мигрируются.
Командный срез подписанного управления, manifest, допуска и Iroh реализован,
включая восстановление нового доверенного набора, ручное извлечение непринятых
источников и очистку ciphertext по удержаниям. [Проверки и ограничения](p2p-acceptance.md)
различают сервисные сценарии и нативный обмен трёх CLI-профилей. Тесты с macOS Keychain
теперь запускаются только явно; обычный check не вызывает системные запросы доступа.
Следующие UI-экраны, UniFFI и полная приёмка безопасности не входят в текущий срез.

## 2. Локальная БД и первая вертикаль интерфейса

Первый macOS-срез включает список БД, экран тестовой разблокировки и список записей
на искусственных данных. Криптографическая проверка продолжается параллельно;
искусственная сессия не считается реализацией аутентификации или хранения паролей.

Первый приоритет реализации — Rust-ядро и macOS-клиент поверх него;
Android подключается после этого среза. [Демонстрационная разработка](demo.md)
использует документы и черновики в памяти процесса.

- [x] Предметные типы и валидация, Automerge-документ, адресные изменения и история
  первого среза; тесты двух реплик без сети.
- [x] Общий Rust-сервис с тестовой разблокировкой, изоляцией БД, поколениями сессий
  и явным восстановлением временного черновика; сценарные проверки.
- [x] Реализован macOS demo на GPUI + Kit поверх общего Rust API: БД, группы,
  записи, редактор и история, поиск, тестовая блокировка, en/ru и оформление.
  Сборка и smoke сервисного сценария пройдены. Владелец подтвердил завершение
  приёмки текущего macOS demo 2026-09-09; следующий шаг — продуктовая реализация
  Rust-ядра и macOS UI. Отдельные проверки macOS 15 и Android остаются открытыми.
