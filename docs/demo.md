# Режимы macOS-приложения

Обычный запуск открывает [UI по макетам](macos-ui.md), подключённый к Rust runtime.
Создание и открытие используют настоящие экспериментальные `.taypeer`-файлы,
мастер-пароль и отдельный процесс для каждой БД.

## Запуск

Из корня репозитория на Apple Silicon Mac:

```sh
rtk cargo run --locked -p taypeer
```

Для локального неподписанного `.app`:

```sh
rtk proxy sh scripts/build-macos.sh
rtk open -n "target/Taypeer Demo.app"
```

Скрипт включает [иконку Taypeer](../wireframes/assets/taypeer-app-icon-v1.md)
и безоконный AppKit helper в `.app`. Производные файлы остаются в `target/`.
Сборка требует macOS 15+ ARM64. Это локальная сборка, не подписанный выпуск.

Прежний сервисный UI и его режимы запуска удалены. Работа с экспериментальными
файлами доступна через UI, [Rust API и CLI](core-cli.md).

## Проверка без окна

В том числе на Ubuntu:

```sh
rtk cargo run --locked -p taypeer -- --smoke-test
rtk proxy sh scripts/check.sh
```

[Smoke](../apps/taypeer/src/smoke.rs) проверяет создание, редактирование,
историю, поиск, поколения сессий и восстановление черновика через Rust-сервис.
Он использует публичные искусственные данные и не подтверждает работу GPUI.
Этот сервисный сценарий отделён от файлового UI.

## Границы

UI содержит компоненты GPUI Kit, сторы представлений и фоновый адаптер Rust-команд.
БД сохраняются в выбранные файлы, черновики — в зашифрованные sidecar. Touch ID,
новые экраны обмена, устройств, корзины и конфликтов остаются отдельной работой.
Открытые проверки безопасности перечислены в [roadmap](roadmap.md).

[Проверки UI](testing.md#новый-macos-ui--2026-09-15) описывают текущие сценарии и ограничения приёмки.
Исследовательские workspace в `spikes/` остаются изолированными.
