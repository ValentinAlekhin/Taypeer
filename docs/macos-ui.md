# macOS UI на демонстрационных данных

Обычный запуск `cargo run --locked -p taypeer` открывает новый UI по
[макетам](../wireframes/README.md). GPUI Kit предоставляет поля, многострочный ввод,
дерево, таблицу, меню, переключатели, диалоги и изменяемые панели.

## Граница этого этапа

Все БД, группы, записи, история, черновики и настройки демонстрационной защиты
живут в памяти процесса. «Открыть» выбирает публичный образец; разблокировка принимает
любой непустой тестовый пароль. «Создать» проверяет повтор пароля формы и открывает
пустую демобазу. Пароль формы не становится ключом. Прототип не вызывает
`DatabaseService`, файловый формат, worker, криптографию или сеть.

Сохраняются только существующие настройки оформления: язык, тема, размер текста,
ширина дерева и таблицы. Используется прежний формат `preferences.toml`;
ошибка чтения/записи видна в интерфейсе. Повреждённый файл не перезаписывается.
После перезапуска восстанавливается оформление и начальные публичные образцы.

## Владельцы состояния

| Владелец | Ответственность |
| --- | --- |
| [AppView](../apps/taypeer/src/macos/ui/mod.rs) | Композиция окна, время жизни экранов и клавиатурный фокус |
| [WorkspaceStore](../apps/taypeer/src/macos/ui/workspace.rs) | Переходы, открытые демобазы, поиск, выбор, вкладки, Save/Discard/Stay |
| [NavigationState](../apps/taypeer/src/ui_state/navigation.rs) | Чистая модель навигации, сортировка и проекция поиска |
| [CatalogStore](../apps/taypeer/src/ui_state/catalog.rs) | Искусственные записи и версии, команды подтверждения в памяти |
| [EditorStore](../apps/taypeer/src/ui_state/draft.rs) | Один черновик трёх редактируемых вкладок, исходное значение и ошибки формы |
| [PreferencesStore](../apps/taypeer/src/macos/ui/appearance.rs) | Оформление, локализация и единственная запись на диск |
| Компоненты `header`, `sidebar`, `entries`, `inspector`, `editor`, `session`, `settings` | Отображение, фокус, прокрутка, ввод и подписки по времени жизни |
| `forms`, `icons`, `generator`, `style` | Повторяемые формы, локальные ресурсы и общая сетка полей |

Сторы представлены `Entity<T>` GPUI. Навигация доступна компонентам только для
чтения; изменение выполняется именованными командами стора. Виджеты ввода — адаптеры
черновика, а не вторые владельцы подтверждённых записей. ID БД, группы и записи
имеют разные типы. Модель состояния не импортирует GPUI и проверяется на всех hosts.
LikeC4: `macosUi` и `uiEdit` в [модели](../architecture/macos-ui.c4).

## Реализованные сценарии

- Приветствие, создание, выбор, демоблокировка, переключение и закрытие БД.
- Дерево групп, создание/редактирование группы, выбор иконки и контекстное меню.
- Таблица, поиск в текущей/всех разблокированных БД, возврат к результатам,
  сортировка по ID-сохранённому выбору и включение дополнительных колонок.
- Обзор, Дополнительно, Вид, Свойства и История. Общий черновик первых трёх
  вкладок; сохранение и отмена сверху, без дублирующих кнопок внизу.
- Атрибуты с маской, демовложения (метаданные), иконки и цвета, генератор
  публичного образца, просмотр/сравнение/восстановление/очистка истории.
- Настройки устройства и демобазы, en/ru, system/light/dark и масштаб текста.

Save/Discard/Stay защищает выход из изменённой записи и изменённых вспомогательных
форм. Блокировка закрывает диалоги и виджеты редактора; изменённый общий черновик
можно явно восстановить после нового входа. Поиск исключает пароль, защищённые
атрибуты и заблокированные демобазы. Подтверждение не означает сохранение файла.

## Клавиатура

| Команда | Действие |
| --- | --- |
| Cmd-O / Cmd-Shift-N | Выбрать образец / создать демобазу |
| Cmd-N / Cmd-E | Новая запись / редактировать выбранную |
| Cmd-S / Escape | Подтвердить / выйти с проверкой черновика |
| Cmd-F | Поиск |
| ↑ / ↓ / Enter в таблице | Выбрать строку / редактировать |
| Cmd-L | Демоблокировка, в том числе при открытой форме |
| Cmd-, / Cmd-W / Cmd-Q | Настройки / закрыть окно с проверкой черновика |

## Ограничения

Вложения представлены именем и размером; «скачивание» показывает уведомление.
Загрузка иконки подставляет локальный образец. Генератор детерминированный и
помечен как демонстрационный, без оценки криптографической стойкости. Таймеры,
Touch ID и relay меняют только UI-настройки. Корзина, удаление/клонирование групп,
устройства, обмен, конфликты и управление будут следующими экранами.

Этот этап не подтверждает безопасность хранения, физическое затирание памяти,
интеграцию платформенных событий, macOS 15, IME или Android.
